## Tennis for two HD

This is a modern reproduction of ["Tennis for two"](https://de.wikipedia.org/wiki/Tennis_for_two) one of the first video games ever made.

The code is structured with a common part in the `Common` folder and chip specific subprojects.

### Variants
#### F303k-NUCLEO 
Designed for the official STM32F303k-Nucleo devboard for use in DIY and Breadboard builds.
