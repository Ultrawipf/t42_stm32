## Tennis for two HD

This is a modern reproduction of ["Tennis for two"](https://de.wikipedia.org/wiki/Tennis_for_two) one of the first video games ever made.

The code is structured with a common part in the `Common` folder and chip specific subprojects.

### Variants
#### F303k-NUCLEO 
Designed for the official STM32F303k-Nucleo devboard for use in DIY and Breadboard builds.

Pinouts:
Signal | Pin
---|---
X-Out | A3 (PA4)
Y-Out | A4 (PA5)
Pot left | A0 (PA0)
Pot right | A1 (PA1)
Btn left | A5 (PA6)
Pot left | A6 (PA7)
LED right | D12 (PB4)
LED left | D13 (PB3)

#### F303CB
The latest all in one kit with optional potentiometers and connectors for controllers.

Designed for collections, museums and integrated setups.

The kit is available on [Lectronz](https://lectronz.com/products/LRAzdcngy_EcO1HJ9iuZsVuRM_s1uEzY95U8oW_G/preview).

#### L151
First version shown in the [Project video](https://www.youtube.com/watch?v=GjI3_GtFCSo).

Schematics are available in this repo.
